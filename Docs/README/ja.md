# Kawaikara WebExtension

[English](../../README.md) · [한국어](ko.md)

Kawaikara の Provider が提供するブラウザーメニューやページ機能を利用できます。
動画を Kawaikara で開く、ダウンロードするなど、利用できる機能はインストールされた
Provider によって決まります。拡張機能はブラウザーと Kawaikara を接続し、
ユーザーが有効にした Provider の機能を適用します。

## インストール

**Google Chrome 121 以降**、**Mozilla Firefox 140 以降**と対応する Kawaikara アプリが必要です。

ローカルビルドは[ビルドガイド](../Build.md)に従い、ブラウザーに読み込みます。

- **Chrome:** `chrome://extensions` でデベロッパーモードを有効にし、**パッケージ化されていない拡張機能を読み込む**から `dist/chrome` を選択します。
- **Firefox:** `about:debugging#/runtime/this-firefox` の **一時的なアドオンを読み込む**から `dist/firefox/manifest.json` を選択します。このインストールは Firefox の終了時に解除されます。

## 使い方

1. Kawaikara を起動し、**設定 → 詳細設定 → 拡張機能を使用**を選択します。
2. 既定のブラウザーで接続ページが開きます。接続が成功すると、同じタブが拡張機能の設定に切り替わります。そのブラウザーで拡張機能をインストールし、有効にしてください。
3. 使用する Provider の WebExtension 機能を選び、**適用**を押してまとめられた権限要求を許可します。
4. 対応サイトで Provider のメニューやページ機能を使用します。

拡張機能の設定から接続を開始し、Kawaikara で許可することもできます。
Provider は個別に有効・無効を切り替えられます。接続を解除すると接続情報とキャッシュされた機能が削除されます。

アプリが終了していても、許可済みの機能はキャッシュに保持されます。機能を使うと
Kawaikara の起動と再接続を要求してから実行します。自動起動には OS へのアプリ起動登録が
必要です。開発ビルドでは手動でアプリを起動する必要があります。
